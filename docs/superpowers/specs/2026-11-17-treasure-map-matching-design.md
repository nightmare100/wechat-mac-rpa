# 藏宝图匹配与去重收录设计

## 目标

新增独立的 `src/treasure_map/` 模块，先提供命令行，后续由微信机器人复用：

- 输入未全开的藏宝图，从 `images/` 中查找同一棋盘布局；证据不足或结果有歧义时明确返回找不到。
- 输入已全开的藏宝图，若相同布局已存在则返回已重复及原图路径，否则加入 `images/added/`。

用户已确认采用局部特征方案并开始执行。本阶段不接微信、不发送消息、不自动提交 Git。

## 判定语义与边界

“相似”指道具及其在棋盘上的位置一致，不是文件字节相同或画风相近。忽略玩家昵称、倒计时、聊天内容、活动皮肤、分辨率与常见图片压缩差异。完全相同的文件用 SHA-256 快速识别。

支持本游戏界面的完整截图及部分格子被遮挡的截图。第一版不支持任意旋转、拍照透视或只截下一小个道具；`add` 信任调用方传入的是全开图，不自动判断是否全开。

现有图库约 148 张春节皮肤 PNG，均为 828×1792；真实查询样本位于 `input_img/`，包含万圣节皮肤及 1216×2688、843×1864 等尺寸。因此不能依赖固定背景色或全图的固定棋盘坐标。

## 方案比较

- **采用：SIFT 局部特征 + 几何校验。** 对中央候选区域提取特征，进行双向描述子匹配，保留互为最佳匹配的点，再按同一界面允许的受限平移剔除位置不一致的点。能容忍遮挡、皮肤和尺寸差异，不允许任意旋转、缩放或平移把重复道具错误对齐。
- 不采用像素/网格哈希：未开格、皮肤和比例变化会显著改变像素，规则脆弱。
- 不采用多模态向量：擅长语义与画风相似，不能保证布局级去重。

## 实现

- `features.py`：读取并校验图片，裁剪全宽、纵向 24%～82% 的中央候选区域，将宽度归一化为 828 像素；屏蔽棋盘上方横幅及棕色/紫色未开格，提取最多 2500 个 SIFT 特征。缓存关键点坐标和描述子到 Git 忽略的 `data/treasure_map/`。
- `matcher.py`：Lowe 比率初筛、双向互为最佳匹配、受限平移几何校验，并统计内点、内点比例和空间覆盖格数。每个 8×8 空间区域最多贡献 5 个计分内点，避免一个复杂道具主导结果。候选按综合分数排序。
- `library.py`：递归扫描 PNG/JPEG/WebP，计算查询与全部图库图片的相似度；`match` 使用部分图阈值和歧义检查，`add` 使用更严格的全开图重复阈值。阈值以真实样本校准，宁可拒识也不强行匹配。
- 新图保存为 `images/added/<sha256><原扩展名>`，保留原字节并原子写入；重复时不创建文件。现有图片及 `manifest.json` 不修改，索引缓存不作为图库输入。
- `cli.py` / `__main__.py`：提供 `match`、`add`，输出中文结果，支持 `--json` 供后续 Bot 适配；找不到和已重复都是正常业务结果，不作为程序异常。
- 公共 Python API 返回结构化结果，微信接入只依赖该 API，不解析命令行文本。

## 校准后判定参数

Lowe 比率 0.8；宽度归一化后允许水平位移不超过 25 像素、垂直位移 -150～100 像素，共同平移误差不超过 6 像素。部分图至少 12 个几何内点、2 个空间覆盖格、内点比例 0.20、综合分 30.0。中等强度结果若与第二名差距不足 15% 则判为有歧义并返回找不到；综合分达到 60.0 的强结果不受第二名差距限制。全开重复至少 60 个内点、12 个覆盖格、内点比例 0.35、综合分 40.0。综合分为“每个 8×8 区域最多 5 个内点的计分总数 × 原始内点比例”，空间覆盖作为独立门槛。

## 验证

- 单元测试：图片校验、动态顶部/底部排除、缩放与遮挡匹配、不同布局拒识、空特征、阈值与歧义、缓存复用。
- 收录测试：完全重复及布局重复不写入，新图按哈希命名并完整保存，写入失败不留下半成品，空图库可收录。
- CLI 测试：找到、找不到、已重复、已加入及错误退出码，文本和 JSON 输出一致。
- 本机验证：对 `input_img/input1.png`、`input2.png`、`input3.png` 运行查找，并人工查看最佳候选确认结果；对代表性图库原图、缩放/压缩/模拟遮挡版本做回归。收录写操作只在临时目录测试，不把查询样本加入正式图库。
- 运行新模块测试及现有 `src/tests` 回归，检查父仓库和子模块 diff；不提交、不启动或重启 Bot。

## 本机校准结果

- `input1.png`、`input2.png`、`input3.png` 均返回找不到；人工查看原高分候选确认存在重复道具误对齐，已加入受限平移和空间限分回归。
- 九个帖子目录的代表原图全部找回自身，自匹配分数 274～311；三张代表图的缩放、JPEG 压缩及约三分之二格遮挡版本共九次查询全部找回原图，遮挡正样本分数 35.1～41.1。
- 九张代表图构成的 72 个不同布局方向对，匹配通过数和重复通过数均为 0；负样本最高分 22.1，低于匹配阈值 30 和重复阈值 40。
- 完全重复、JPEG 布局重复均在临时图库返回已重复且不写入；另一张不同布局作为新图可完整写入临时图库。未对正式图库执行 add。
