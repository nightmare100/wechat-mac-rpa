# MuMu Util Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 项目内新增可供未来微信 Bot 调用的 MuMu Python 工具模块。

**Architecture:** `src/mumu/client.py` 封装 subprocess/MuMu CLI/ADB；`models.py` 定义返回值；`__init__.py` 公开类，README 说明 Python 用法。

**Tech Stack:** Python 标准库、MuMu 自带 CLI/ADB、已有 Pillow、pytest。

**Spec:** [设计](../specs/2026-11-15-mumu-util-design.md)

## Global Constraints

- 本期不接 Bot、不自动安装 APK 或输入法、不提交截图或私人配置。
- 截图只从 Android 内部获取，操作明确定位实例。
- 保持当前仓库修改可审查，不自动提交。

## Review Focus

- CLI 退出码为 0 但 JSON 报错时必须失败。
- ADB 端口变化必须重新按实例解析，不能操作其他实例。
- 输入中的 shell 符号不能变成 Android 命令。
- 截图失败不能覆盖已有有效图片。
- 序列遇错停止，后续操作不能继续执行。
